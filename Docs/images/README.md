# README Screenshots

Drop the image files listed below into this folder. The main [`README.md`](../../README.md)
references them by these exact names, so once a file exists the placeholder image in the
README resolves automatically - no Markdown edits required.

| File name | What to capture |
|---|---|
| `main-grid.png` | The main window: timer grid populated with timers, tabs across the top, toolbar visible. |
| `mini-views-ingame.png` | One or more mini-view overlays floating over the EverQuest client during play. |
| `timer-config.png` | A timer being configured - Start/End Keyword, Duration, Style, and Speech/WAV fields. |
| `styles-views-tabs.png` | The Styles and/or Views tab showing colors, the style filter, and per-view options. |

## Guidelines

- **Format:** PNG preferred (lossless, crisp text). JPG is fine for in-game shots.
- **Width:** ~1000-1400px is a good target; GitHub scales them down in the table.
- **Crop tight:** show the feature, not the whole desktop.
- **Avoid sensitive info:** account names, server addresses, etc.
- **Keep names lowercase-kebab-case** to match the README references.

> Tip: capture at 100% display scaling so text stays sharp, then crop in any editor.
