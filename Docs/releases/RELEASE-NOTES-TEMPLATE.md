# ⚔️ Thorne Timer v[VERSION]

**Your EverQuest companion — real-time log parsing, overlay timers, and voice alerts crafted for the way you play.**

Thorne Timer watches your log files and turns game events into overlay timers, voice alerts, and notifications — giving you the situational awareness that UI files alone can't provide. Whether you're raiding, soloing, or multi-boxing, it keeps the information you need visible and on screen.

## 📦 Installation

1. Download **`ThorneTimer-v[VERSION].zip`** below
2. Extract to a folder of your choice
3. Run **`ThorneTimer.exe`**
4. Point it at your EQ log file and you're ready to go

> 🔄 **Upgrading?** Your tome (`.tdb` database) will be migrated automatically — all your timers, characters, and settings are preserved.

## 🖥️ Requirements

- Windows with .NET Framework 4.8 (included in Windows 10 1903+)
- EverQuest with logging enabled (`/log on`)
