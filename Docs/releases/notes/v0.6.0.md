_The stable cut of the v0.6.0 series._

This release rolls up everything from the v0.6.0 betas into a stable release -- user-editable styles & views, per-view colors, per-style time formats, camp-out auto-pause, a richer Tome Information dialog, and a repository/manager architecture refactor. See [`v0.6.0-beta.md`](v0.6.0-beta.md) and the per-beta notes for the full feature history.

### New since v0.6.0-beta4

- **Multi-keyword matching.** Separate several phrases with a pipe (`|`) in any Start or End Keyword -- the timer fires if **any** of the alternatives appears. Works for both timer and category keywords, so one timer can cover the different ways the game phrases the same event.
- **Per-cell tooltips across every grid.** The Timers, Categories, Views, Styles, and Characters grids now have hover help on every column -- including an explanation of the multi-keyword pipe -- so new users can learn the UI as they go.

### Fixes since v0.6.0-beta4

- **Style dropdowns stay in sync.** Adding, renaming, or deleting a style now immediately refreshes the style pickers on the Timers and Views tabs, and spurious combo-box binding errors are suppressed.

### Documentation

- **Readme refresh for newcomers.** A new "Working with Timers" walkthrough and "Real-world timer recipes" (pings, buffs-on-you, multi-keyword spawns, and a dependent chain), a "First run" section explaining the SmartScreen warning for unsigned builds, and a player-facing FAQ.
- **Standardized documentation.** Consistent file naming, a STATUS index, and an updated example tome (156 timers) that showcases the styles, views, and multi-keyword features on a fresh install.

### Upgrade notes

> Your `.tdb` tome will be migrated automatically. If you skipped the betas and are coming from v0.5.0, the migration is one-shot -- your customizations stick. As always, back up your tome file before upgrading.
