_The first major release since v0.5.0 — a top-to-bottom GUI overhaul, smarter character and log handling, per-style time formats, multi-keyword matching, a much richer Tome Information dialog, and a deep architecture refactor._

This release consolidates the entire v0.6.0 series into one stable build. Everything below is new since **v0.5.0**.

---

## ✨ Highlights

- **First-class, user-editable Styles** — a dedicated Styles tab to add, rename, recolor, and delete styles.
- **User-configurable Views** — add as many always-on-top overlay windows as you like, each with its own style filter, colors, warning behavior, and empty-state display.
- **Per-style time formats** — render remaining time as Classic, Long, Adaptive Compact, or Full Compact, consistently in both the grid and the mini views.
- **Multi-keyword matching** — separate phrases with a pipe (`|`) in any keyword; the timer fires if *any* alternative appears.
- **Smarter character handling** — a `(None)` character for manual pause, plus camp-out auto-pause on `/camp`.
- **Richer Tome Information dialog** — timer and catalog counts, per-category / style / class / scope breakdowns, and sortable lists.
- **Newcomer-friendly throughout** — per-cell tooltips on every grid, a "Working with Timers" walkthrough, real-world recipes, and a player FAQ.
- **Faster and cleaner under the hood** — per-entity repositories, `FormMain` split into focused managers/controllers, and an ~98% faster grid sync on large tomes.

## 🎨 Styles, Views & Categories

- **Styles tab** — first-class, user-editable styles with Add / Delete / Rename and a color picker.
- **New default styles** — Pet (lavender), Spawn (cyan), Lockout (DodgerBlue), Character (white).
- **Views tab** — Add / Delete views with a dynamic Style filter dropdown, plus per-view ForeColor / BackColor / ShowWarning / EmptyBehavior.
- **Per-view colors** — each view drives its own mini-view appearance and the main grid row tint.
- **Refreshed default colors** — Normal / Buff / Pet / Ping / Spawn / Lockout defaults re-tuned for visibility against the black mini-view background (seeding stays one-shot — existing `.tdb` files keep their saved colors).
- **Softer inactive-row tint** — inactive rows use Gainsboro instead of LightPink so the tint no longer competes with user-chosen red style colors (e.g. Lockout).
- **Hybrid Designer + Controller + Repository pattern** applied across Styles, Views, and Categories tabs.

## ⏱️ Per-Style Time Formats

Each style can choose how its timers render the remaining time — applied consistently in the **mini views** *and* the main grid **Remaining** column:

- **Classic** (default) — `1d 04:05:22` / `01:23:45`.
- **Long** — `1d 4:05:22` / `1:23:45` / `0:45` (collapses the leading unit, right-justified).
- **Adaptive Compact** — `1d 4h` / `1h 23m` / `45s` (the two most-significant units).
- **Full Compact** — `1d 4h 5m 22s` / `1h 23m 45s` / `45s`.

Pick the format from the **Time Format** column on the **Styles** tab; a live **Example** preview shows exactly what you'll get. Existing tomes default every style to **Classic**, so nothing changes until you opt in.

## 🔤 Multi-Keyword Matching

- Separate several phrases with a pipe (`|`) in any Start or End Keyword — the timer fires if **any** of the alternatives appears.
- Works for both timer and category keywords, so one timer can cover the different ways the game phrases the same event.

## 👤 Character & Log Handling

- **`(None)` character** — manual pause without camping out.
- **Camp-out auto-pause** — detects `/camp` with a 10-second inactivity threshold and switches the active character to `(None)`.
- **Auto-switch fixes** — suppress the OLD character (not the new one) on a manual switch, with proper re-enable logic.

## 📊 Tome Information Dialog

- **Richer statistics** — Total / Active / Running timer counts, catalog counts (characters, categories, styles, views, classes), and per-category / style / class / scope breakdowns.
- **Tome version stamping** — a new `db_meta` table records which app version created the tome and which version last wrote to it.
- **Sortable lists** — click any column header on the Feature Usage and breakdown lists to sort; numeric columns sort numerically (10 > 2), text columns alphabetically.
- **Consistent "All" labelling** — unassigned class breakdown rows read **All** to match the main timer grid's class combo.
- **Tighter layout** — split the combined timer summary into individual Total / Active / Running fields and fixed runtime-frame shrinkage.

## 🔊 Voice & Mini Views

- **Mini views hidden from Alt-Tab** via `WS_EX_TOOLWINDOW`.

## ⚙️ Architecture & Performance

- **Per-entity repositories** — Categories, Views, Characters, Classes, Timers, TimerState, and TomeStatistics each own their SQL; `Database.cs` is trimmed to connection / schema / settings plumbing.
- **`FormMain` split into managers & controllers** — RecentDatabasesManager, WindowPositionManager, GridLayoutManager, VoiceManager, MiniViewSettingsManager, plus CharactersController and TimersController. **~600 lines removed from `FormMain.cs`** with no behavior change.
- **Much faster character switching & startup** — the timers grid filters a master list and swaps its data source in a single assignment instead of toggling row visibility one row at a time (which had dominated switch/startup at ~1.8 s on 100+ row grids).
- **Faster grid sync** — O(n²) → O(n) dictionary lookup in `SyncRuntimeToGrid` (~98% faster with 130+ timers), and runtime state is now filtered *before* syncing so only visible timers are walked.
- **One-shot startup migration** — the v0.5.0 → v0.6.0 palette migration runs once; deletions stick, with no snapback.

## 🐛 Notable Fixes

- **Open Database no longer crashes.** Switching tomes via **File → Open Database** could throw `Database is not open` because the Characters grid's row-validation fired while its data source was torn down. Tab controllers are now disposed before grids are rebuilt.
- **Style dropdowns stay in sync.** Adding, renaming, or deleting a style immediately refreshes the style pickers on the Timers and Views tabs, and spurious combo-box binding errors are suppressed.
- **Dependency delays honored under every time format.** Dependent chains using a compact format no longer fire all at once — the dependency check reads authoritative elapsed milliseconds instead of re-parsing the display string.
- **Mini-view warnings are format-independent.** Warning colors are driven by raw remaining milliseconds, so compact formats like `1d 4h` or `45s` no longer trigger false warnings.
- **Lossless timer-state persistence.** Saved remaining times are normalized to canonical `HH:MM:SS` at the storage boundary, so timer state round-trips exactly across restarts regardless of display format.
- **Grid layout fixes.** Characters / Categories grids no longer load misaligned; Styles and Views column widths now persist; row colors and curated column order survive every filter rebuild; and newly-added columns (like Styles "Time Format") fit the existing footprint instead of overflowing a saved layout.

## ⬆️ Upgrade Notes

> ⚠️ **Back up your `.tdb` tome before upgrading.** Coming from v0.5.0, the migration is one-shot and idempotent — your customizations stick and every style defaults to the **Classic** time format, so timers render exactly as they do today. Two schema additions land safely: the `db_meta` version-stamp table and the `styles.TimeFormat` column. Your existing styles, views, timers, colors, and saved column widths are all preserved.
