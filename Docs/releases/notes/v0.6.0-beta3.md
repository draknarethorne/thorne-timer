_Third beta of v0.6.0 — bug fix and About-dialog version display on top of `v0.6.0-beta2`._

### Fixes

- **Open Database no longer crashes.** Switching tomes via **File → Open Database** could throw `Database is not open` (`System.InvalidOperationException`). During the database switch the Characters grid's row-validation fired while its data source was torn down, saving against the just-closed connection. The tab controllers are now disposed (unwiring their validation) before the grids are rebuilt.

### Improvements

- **About dialog shows the pre-release label.** The Help → About version now reflects the full release identity — `0.6.0-beta3`, `0.6.0-beta2`, `0.6.0`, etc. — instead of just the numeric `0.6.0`. Local/dev builds show `0.6.0-dev`. This uses `AssemblyInformationalVersion`, stamped from the git tag at release time.

### Upgrade notes

> ⚠️ **Back up your `.tdb` tome before upgrading.** No schema changes ship in this beta. Includes all fixes from `v0.6.0-beta2` (grid performance, visual polish, column-layout persistence).
