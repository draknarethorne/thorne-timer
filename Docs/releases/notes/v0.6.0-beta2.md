_Second beta of v0.6.0 — performance, polish, and bug fixes on top of `v0.6.0-beta`._

### Performance

- **Much faster character switching & startup.** The timers grid no longer toggles row visibility one row at a time (which cost ~14 ms per row and dominated character switch / startup at ~1.8 s on 100+ row grids). It now filters a master list and swaps the grid's data source in a single assignment.
- **Cheaper cell sync.** Grid refresh now filters *before* syncing runtime state, so only the visible subset of timers is walked.
- **Diagnostic timing.** Added `PERF` timing lines around the startup and character-switch hot paths (form load, runtime load, grid sync/refresh, filter refresh) so slow paths are measurable in the diagnostic log.

### Visual polish

- **Refreshed default style colors.** Normal / Buff / Pet / Ping / Spawn / Lockout defaults were re-tuned for visibility against the black mini-view background. (Seeding stays one-shot — existing `.tdb` files keep their saved colors.)
- **Softer inactive-row tint.** Inactive timer rows changed from LightPink to Gainsboro so the row tint no longer competes with user-chosen red style colors (e.g. Lockout).

### Grid column layout — fixes

- **Tab grids no longer load misaligned.** The Characters and Categories grids (and any other Fill-mode grid) could load with columns squeezed too small or out of proportion. Restored column proportions are now applied correctly for tabs that haven't been shown yet.
- **Styles grid column widths now persist.** Previously column widths were loaded but never saved, so adjustments were lost on restart. They're now saved on close.
- **Views grid column widths now persist.** The Views tab grid is now saved and restored like every other grid.

### Grid correctness fixes (data-source swap follow-ups)

- **Row colors survive filtering.** Re-binding the grid created fresh rows with default styles, dropping the inactive-row tint and the lightened running-row color; row colors are now re-applied after every filter rebuild.
- **Column order survives filtering.** Re-binding reset each column's `DisplayIndex`; the curated column order (Play / Count / Start, etc.) is now restored after every bind.

### Cleanup

- **Removed the throwaway rendering spike.** The internal layered-window proof-of-concept (`Spike\LayeredMiniViewSpike.cs`) that shipped in `v0.6.0-beta` has been removed from the build; its validated plumbing was preserved in the design docs for the upcoming mini-view skin engine.

### Upgrade notes

> ⚠️ **Back up your `.tdb` tome before upgrading.** No schema changes ship in this beta, but a backup is always wise on a beta build. Existing saved column widths and style colors are honored automatically — the Characters/Categories alignment fix takes effect on first load, and fresh, correct widths are written the next time you close the app.
